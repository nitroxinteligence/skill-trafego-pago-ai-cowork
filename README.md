# Agente de Tráfego Pago & Meta Ads (`skill-trafego-pago-ai-cowork`)

> Skill oficial distribuída pela **AI Cowork Academy** para empresários e gestores estruturarem **Tráfego Pago & Anúncios** com Agentes de IA.

## O que este agente faz

Estrutura campanhas de Facebook e Instagram Ads, segmentação de públicos, remarketing, orçamento e otimização de ROAS.

## Como instalar em 1 comando

Copie e cole este prompt direto na sua IA (Claude Code, Codex, ChatGPT ou Antigravity):

```text
Acesse o repositório https://github.com/nitroxinteligence/skill-trafego-pago-ai-cowork, leia o arquivo SKILL.md completo (e a pasta references/) e instale esta skill no meu workspace para eu usar agora.
```

## Como utilizar na prática

Informe seu orçamento mensal, oferta, público-alvo e métricas atuais (se já anuncia). O agente monta a estrutura de campanha, testes de criativos e plano de otimização.
